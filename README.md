# تطبيق يحيى — PWA

هذا مشروع بداية لتطبيق روتين يحيى، مبني على التصميم الذي أرسلته صاحبته. تم تضمين الصورة المرجعية وقصاصات من الرسومات الأصلية لاستخدامها داخل الواجهة.

## الموجود حاليًا
- ثلاث صفحات: الصباح، بعد المدرسة، والجدول اليومي.
- قائمة شنطة المدرسة في صفحة الصباح.
- تلوين صفوف الأنشطة في صفحة الجدول اليومي فقط.
- مربعات إنجاز المهام.
- سحب وإفلات لإعادة ترتيب مهام الجدول اليومي على الكمبيوتر، ودعم لمس مبدئي للموبايل.
- حفظ الترتيب وحالة الإنجاز محليًا على الجهاز.
- إعدادات PWA للتثبيت على الموبايل.

## رفع الملفات إلى GitHub
1. افتحي مستودع Yahia.
2. اختاري **Add file → Upload files**.
3. ارفعي محتويات المجلد كاملة، وليس ملف ZIP فقط. لازم يكون `index.html` في جذر المستودع.
4. اضغطي **Commit changes**.
5. من **Settings → Pages** اختاري **Deploy from a branch** ثم الفرع `main` والمجلد `/(root)` ثم **Save**.
6. انتظري اكتمال النشر وافتحي رابط GitHub Pages. قد يستغرق النشر بضع دقائق.

## ملاحظات
- التطبيق واجهة أولية قابلة للتشغيل، وليست نسخة نهائية مطابقة بالبكسل لكل تفاصيل الصورة.
- تم قص بعض الرسومات من الصورة المرجعية المرفقة؛ قد تحتاج بعض القصاصات إلى تحسين حوافها أو استبدالها بملفات أصلية عالية الدقة للحصول على تطابق أدق.
- البيانات تحفظ على نفس المتصفح والجهاز، ولا يوجد تسجيل دخول أو مزامنة بين الأجهزة.
- الخط العربي يُحمّل من Google Fonts عند توفر الإنترنت، مع خطوط بديلة عند عدم توفره.
